Tune these, then generate a board you can save.

Tap a queue-top car to load it onto a truck. Other colors still use the parking lots.

Car difficulty only changes how cars are mixed in the queues. Truck difficulty only changes how truck colors line up with those tops. Unique colors, per-color packs, capacity, and hidden stay as you set them.

Generate only keeps a seed the winnable-path checker accepts. Chip edits are not checked until you press Check winnable.

Each color has its own pack count. Default is 3; 5 and higher (up to 8) are allowed.

Givens are reserved from each color’s column count. Weights below pick how full each reserved dest is: empty, 1, 2, or 3. Same-color givens do not merge. A cleared dest takes the next reserved given.
